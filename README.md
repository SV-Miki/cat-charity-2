# Проект QRKot

## Описание проекта

QRKot - API-приложение благотворительного фонда поддержки котиков.

Фонд открывает целевые проекты для помощи кошкам, котам и котятам: сборы на корм, лечение, содержание приютов и другие задачи. Пользователи регистрируются в сервисе, отправляют пожертвования в фонд, а приложение автоматически распределяет полученные средства между открытыми проектами.

В приложении настроены регистрация и аутентификация пользователей через JWT-токены. Пожертвования персонализированы: в базе данных сохраняется пользователь, который сделал пожертвование.

Проект позволяет:
- создавать целевые благотворительные проекты
- получать список всех целевых проектов
- редактировать открытые целевые проекты
- удалять проекты, в которые ещё не были внесены средства
- создавать пожертвования
- получать список всех пожертвований
- автоматически инвестировать пожертвования в открытые проекты
- автоматически закрывать проект после сбора нужной суммы
- автоматически закрывать пожертвование после полного распределения средств
- сохранять данные в базе SQLite
- управлять структурой базы данных через Alembic
- работать с API через Swagger-документацию
- регистрировать и аутентифицировать пользователей
- разграничивать доступ к эндпоинтам по ролям
- сохранять автора каждого пожертвования
- показывать пользователю список его пожертвований
- ограничивать управление проектами только для суперпользователей

## Логика инвестирования

Пожертвования не привязываются пользователем к конкретному проекту.
После создания нового пожертвования приложение автоматически ищет самый старый открытый проект и направляет деньги в него. Если сумма пожертвования больше, чем требуется проекту, проект закрывается, а остаток пожертвования направляется в следующий открытый проект.
Если открытых проектов нет, пожертвование остаётся нераспределённым и ждёт появления нового проекта.
После создания нового проекта приложение автоматически проверяет, есть ли свободные пожертвования, и инвестирует их в новый проект.

Пример:

| Действие                                    | Результат                                           |
|---------------------------------------------|-----------------------------------------------------|
| Создан проект на 1000                       | Проект открыт, собрано 0                            |
| Создано пожертвование на 400                | В проект инвестировано 400                          |
| Создано пожертвование на 600                | Проект собрал 1000 и закрыт                         |
| Создано пожертвование без открытых проектов | Деньги ждут нового проекта                          |
| Создан новый проект                         | Свободные пожертвования автоматически инвестируются |


## Права доступа

### Анонимный пользователь

Может:

* просматривать список всех целевых проектов
* регистрироваться в сервисе

Не может:

* создавать пожертвования
* просматривать пожертвования
* создавать, редактировать и удалять целевые проекты

### Авторизованный пользователь

Может:

* просматривать список всех целевых проектов
* создавать пожертвования
* просматривать список своих пожертвований
* получать и обновлять свои пользовательские данные

Не может:

* создавать, редактировать и удалять целевые проекты
* просматривать список всех пожертвований
* редактировать или удалять пожертвования
* удалять пользователей

### Суперпользователь

Может:

* просматривать список всех целевых проектов
* создавать, редактировать и удалять целевые проекты
* создавать пожертвования
* просматривать список своих пожертвований
* просматривать список всех пожертвований
* просматривать и обновлять данные пользователей

Не может:

* удалять пользователей
* редактировать или удалять пожертвования
* редактировать или удалять закрытые проекты
* удалять проекты, в которые уже были инвестированы средства
* изменять даты создания и закрытия проектов

## Ограничения

Для целевых проектов:

* название проекта обязательно
* название проекта должно быть уникальным
* длина названия проекта - от 5 до 100 символов
* описание проекта обязательно
* длина описания - не менее 10 символов
* требуемая сумма должна быть больше 0
* закрытый проект нельзя редактировать
* нельзя установить требуемую сумму меньше уже инвестированной
* нельзя удалить проект, в который уже были внесены средства

Для пожертвований:

* сумма пожертвования обязательна
* сумма пожертвования должна быть больше 0
* комментарий к пожертвованию необязателен
* пожертвование может создать только авторизованный пользователь
* пользователь может видеть только свои пожертвования без служебных полей
* суперпользователь может видеть полный список пожертвований

Для пользователей:

* email обязателен
* пароль обязателен
* пароль должен содержать не менее 3 символов
* удаление пользователей отключено

### Проверка Postman-коллекции

В проекте есть Postman-коллекция:

`postman_collection/QRKot_2.postman_collection.json`

Перед запуском коллекции рекомендуется использовать чистую базу данных:

```bash
rm qrkot.db
```

```bash
python -m alembic upgrade head
```

Для подготовки суперпользователя выполните:

```bash
python setup_for_postman.py
```

Скрипт создаёт суперпользователя для Postman-коллекции:

```text
email: root@admin.ru
password: root
```

После этого запустите сервер:

```bash
python -m uvicorn app.main:app --reload
```

После этого коллекцию можно импортировать в Postman и запустить через Run collection.

Важно: коллекция рассчитана на последовательный запуск запросов на чистой базе данных.
