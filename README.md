# QRKot

## Описание

QRKot — API-приложение благотворительного фонда поддержки котиков.

Фонд открывает целевые проекты для помощи кошкам, котам и котятам: сборы на корм, лечение, содержание приютов и другие задачи. Пользователи регистрируются в сервисе и делают пожертвования, а приложение автоматически распределяет полученные средства между открытыми проектами.

В приложении реализованы регистрация и аутентификация через JWT-токены, разграничение доступа по ролям и персонализированные пожертвования с привязкой к пользователю.

Основные возможности:

- регистрация и аутентификация пользователей
- создание пожертвований авторизованными пользователями
- просмотр пользователем только собственных пожертвований
- управление целевыми проектами суперпользователями
- публичный просмотр списка целевых проектов
- автоматическое распределение пожертвований между открытыми проектами по принципу FIFO
- автоматическое закрытие полностью профинансированных проектов
- сохранение нераспределённых пожертвований до появления новых проектов
- разграничение доступа для анонимных пользователей, пользователей и суперпользователей
- хранение данных через SQLAlchemy
- управление схемой базы данных через Alembic
- интерактивная документация API через Swagger

## Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/SV-Miki/cat-charity-2.git
cd cat-charity-2
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv venv
```

#### Linux/macOS

```bash
source venv/bin/activate
```

#### Windows PowerShell

```powershell
venv\Scripts\Activate.ps1
```

#### Windows Command Prompt

```cmd
venv\Scripts\activate.bat
```

### 3. Установить зависимости

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Настроить переменные окружения

Создайте `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Пример конфигурации:

```dotenv
SECRET=change-me
DATABASE_URL=sqlite+aiosqlite:///./qrkot.db
```

Для реального окружения значение `SECRET` необходимо заменить на собственный секретный ключ.

`DATABASE_URL` используется как приложением, так и Alembic, поэтому подключение к базе данных настраивается в одном месте.

### 5. Применить миграции

```bash
python -m alembic upgrade head
```

### 6. Запустить приложение

```bash
python -m uvicorn app.main:app --reload
```

После запуска API доступен по адресу:

`http://127.0.0.1:8000`

## Логика инвестирования

Пользователь не выбирает конкретный проект при создании пожертвования.

Средства автоматически распределяются между открытыми проектами по принципу FIFO: в первую очередь финансируется проект, созданный раньше остальных.

Если пожертвования хватает для полного финансирования проекта, проект закрывается. Оставшаяся сумма автоматически направляется в следующий открытый проект.

Если открытых проектов нет, нераспределённая часть пожертвования сохраняется. При создании нового проекта приложение автоматически направляет в него ранее нераспределённые средства.

Пример:

| Действие                                    | Результат                                                 |
|---------------------------------------------|-----------------------------------------------------------|
| Создан проект на 1000                       | Проект открыт, инвестировано 0                            |
| Создано пожертвование на 400                | В проект инвестировано 400                                |
| Создано пожертвование на 600                | Проект полностью профинансирован и закрыт                 |
| Создано пожертвование без открытых проектов | Средства остаются нераспределёнными                       |
| Создан новый проект                         | Свободные пожертвования автоматически направляются в него |

## Права доступа

### Анонимный пользователь

Может:

- просматривать список целевых проектов
- регистрироваться в сервисе

Не может:

- создавать пожертвования
- просматривать пожертвования
- создавать, редактировать и удалять проекты

### Авторизованный пользователь

Может:

- просматривать список целевых проектов
- создавать пожертвования
- просматривать только собственные пожертвования
- получать и обновлять собственные пользовательские данные

Не может:

- создавать, редактировать и удалять проекты
- просматривать полный список пожертвований
- редактировать или удалять пожертвования
- удалять пользователей

### Суперпользователь

Дополнительно может:

- создавать, редактировать и удалять целевые проекты
- просматривать полный список пожертвований
- просматривать и обновлять данные пользователей

Ограничения сохраняются и для суперпользователя:

- нельзя удалять пользователей
- нельзя редактировать или удалять пожертвования
- нельзя редактировать закрытые проекты
- нельзя удалять проекты, в которые уже были инвестированы средства
- нельзя изменять даты создания и закрытия проектов

## Валидация данных

Для целевых проектов:

- название обязательно
- название должно быть уникальным
- длина названия — от 5 до 100 символов
- описание обязательно
- длина описания — не менее 10 символов
- требуемая сумма должна быть положительным целым числом
- закрытый проект нельзя редактировать
- требуемую сумму нельзя установить ниже уже инвестированной
- проект с внесёнными средствами нельзя удалить

Для пожертвований:

- сумма обязательна
- сумма должна быть положительным целым числом
- комментарий необязателен
- создать пожертвование может только авторизованный пользователь
- обычный пользователь получает только собственные пожертвования без служебных инвестиционных полей
- полный список пожертвований доступен только суперпользователю

Для пользователей:

- email обязателен
- пароль обязателен
- минимальная длина пароля — 3 символа
- удаление пользователей через API отключено

### Postman

Коллекция находится в:

```text
postman_collection/QRKot_2.postman_collection.json
```

Подробная инструкция находится в:

```text

```

Для запуска коллекции требуется чистая база данных и тестовый суперпользователь:

```bash
python setup_for_postman.py
```

Скрипт создаёт локальную тестовую учётную запись:

```text
email: root@admin.ru
password: root
```

Эти данные предназначены только для локального запуска Postman-коллекции.
